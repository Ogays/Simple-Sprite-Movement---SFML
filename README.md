# Simple-Sprite-Movement---SFML
Simple Example Sprite Movement. Walk Animation and Collision Demonstration - SFML.

You need :
* cmake min version 4.2.3
* C++17
* Linux Ubuntu

```
$ git clone https://github.com/Ogays/Simple-Sprite-Movement---SFML.git/
$ cd Simple-Sprite-Movement---SFML/
$ mkdir build/
$ cd build/
$ cmake -S .. -B .
$ make
$ cp Simple-Sprite-Movement---SFML ..
$ cd ../
$ ./Simple-Sprite-Movement---SFML
```
